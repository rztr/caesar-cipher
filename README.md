# Шифр Цезаря

**Автор:** rztr

Консольная программа: шифрует и расшифровывает текстовый файл сдвигом по алфавиту, а без ключа подбирает его перебором по частотам русских символов.

## Запуск

Требуется Java 17 и Maven.

```
mvn compile
java -cp target/classes com.javarush.caesar.MainApp
```

Или запустите `MainApp` из IDE.

## Меню

1. Зашифровать файл
2. Расшифровать файл с ключом
3. Взломать перебором ключей
0. Выход (или `exit`)

## Примеры

Зашифровать `text/input.txt` с ключом 3:

```
Выберите действие: 1
Введите имя файла для шифрования: text/input.txt
Введите имя файла для результата: text/encrypted.txt
Введите ключ: 3
```

Расшифровать тем же ключом:

```
Выберите действие: 2
Введите имя файла для расшифровки: text/encrypted.txt
Введите имя файла для результата: text/decrypted.txt
Введите ключ: 3
```

Взломать без ключа:

```
Выберите действие: 3
Введите имя файла для расшифровки: text/encrypted.txt
Введите имя файла для результата: text/bruteforce.txt
```

## Правила

- Файл результата не должен существовать, иначе будет ошибка.
- Ключ - целое число; ключ вне диапазона приводится к длине алфавита. Нечисловой ключ (`abc`) или слишком большой даёт сообщение об ошибке.
- Символы вне алфавита остаются без изменений.
